- 设置页提示改为「系统设置 → 应用 → 关联启动」，不再指向应用内的按钮。

- README 与市场说明同步改写。

### 仍然需要知道的前置

关联启动未放行时，QQ 无法在后台拉起知弦读取设置，`/healthz` 的 `config_status` 会是
`provider-unavailable:…`，QQ 继续使用原文件/默认配置。放行后重新启动 QQ 即可读到；
普通版与 stealth 版都需要放行。沿用包名与签名，可直接覆盖升级，已保存的设置不变。
