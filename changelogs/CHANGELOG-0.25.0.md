## 0.25.0 · 知弦

这一版把管理页从"能用的原生控件"重做成一套有据可依的界面：令牌、组件、页面三层分离，
四个设计体系各归其位，无障碍按 WCAG 2.2 AA 逐条落地，并且把"界面对不对"变成可自动判定的验收项。
协议、注入与看守一行未动。

### 设计体系

界面分三层，依赖单向：**令牌** → **组件** → **页面**。

- **令牌**：颜色在 `res/values/tokens.xml` 与 `res/values-night/tokens.xml`（深浅两套角色逐条对应），
  间距、形状、字级、动效、断点与可触达下限在 `res/values/dimens.xml`。`ui/Tokens.java` 是唯一读口。
  页面里不再出现字面色值与像素。
- **组件**：`ui/Widgets.java` 提供按钮（实心/填充色调/描边/文字/破坏性）、开关、输入框、卡片、
  状态条、定义列表与确认弹窗，每个都带波纹、可见焦点环与按压形状形变。
- **页面**：`ui/MainActivity.java` 只负责排版与状态，宽度与列数交给 `ui/Responsive.java` 的断点。

四个体系的分工与冲突裁决写在 `docs/ARCHITECTURE.md` 的「管理页界面」：M3E 给颜色角色、字级、
形状刻度与按压表达；HIG 给交互（一屏一个主操作、破坏性操作先确认且默认焦点在「取消」、
"减弱动态效果"生效）；Carbon 给响应式栅格与复杂信息界面（诊断页改成一行的定义列表）；
Miuix 只做视觉精修（更大圆角、靠表面明度分层、默认不画分隔线）。

**不跟随系统动态取色**。动态色无法为任意壁纸保证 4.5:1，也会与固定源色的应用图标分叉；
按裁决顺序，可用性与产品一致性都排在 M3E 之前，所以只认经过对比度验证的那套色板。

### 界面改动

- 三个页面的标题字级、区块标题字级、卡片圆角与内边距全部统一；`md_primary` 与 `artwork/icon.svg`
  同源（此前界面是 `#5D438B`、图标是 `#6750A4`，是两套紫）。
- 状态页的"本机服务"卡片按状态换语义色与文案：就绪是成功色、等待登录与服务待恢复是警告色、
  未连接是错误色；**色彩只作加强，文字本身已说清状态**。
- 诊断页的"运行数据"从一段带空行的长文本改成定义列表（名称 — 值），窄屏与放大字号下自动竖排。
- 状态页与诊断页各有一个刷新入口，探测期间置灰；设置页的主操作是保存，不放刷新。
- 设置页的三连令牌按钮改窄内边距，不再把"生成令牌"挤成两行；保存按钮在无改动时是真正的禁用外观
  （容器降到 on-surface 12%），不再是"看起来能点"。
- 卡片与按钮的按压有形状形变与回弹，全部走令牌里的时长与缓动；开关打开减弱动态效果时只留颜色变化。
- **字距**：令牌里保留 M3 的字距表，但中文界面下整体缩到 0——正字距是为拉丁文设计的，
  用在汉字上会把字拆散。换算时也修了一个真 bug：M3 的字距是 sp，`setLetterSpacing` 收的是 em。
- 顶部把系统栏高度算进内边距，内容不压到状态栏与手势条下面。

### 无障碍（WCAG 2.2 AA）

- 文字角色两两组合 ≥ 4.5:1，非文字边界（输入框描边、开关轨、焦点环）≥ 3:1，深浅两套逐对校验。
- 可点控件不小于 48dp；图标一律装饰性，语义由 `contentDescription` 承担；输入框用 `labelFor` 关联标签。
- 状态文字（服务状态、守护状态、配置状态、诊断提示）标成 `polite` live region，内容变化会被读屏朗读。
- 可聚焦控件有可见焦点环，输入框用描边换色；焦点环颜色与底色保持 3:1 以上对比。
- 字号用 sp，200% 字号 + 320dp 宽下逐页检查文字不截断、不横向滚动。
- 每个页面都有可跳转的标题层级。

### 测试

- 新增 `tests/DesignTokenTest`（接进 `./test.sh`）：解析令牌文件校验深浅角色齐整、逐对算对比度、
  刻度单调、行高不小于字号、可触达下限、动效时长递增、缓动是四个控制点，
  以及**界面代码里不许出现 `#RRGGBB` 字面量**、图标源稿必须与 `md_primary` 同源。
- 恢复并重写 `tests/ui/`：`run.sh` 装机跑真机设计冒烟，验证令牌能在运行期解析出来、
  交互契约、可触达面积、焦点环真的画得出来（画像素判断）、状态 live region、大字号重排，
  并把 light / dark / large-text-320dp 各三页的排版存进 `build/design-tests/design-review/`。
- 修掉一个真实卡顿：root 调用（`su`，最长 20 秒超时）与网络探针、保存原本共用一条单线程队列，
  一次慢的 root 调用会连带堵住"保存设置"与"刷新状态"，现在各走各的线程。
