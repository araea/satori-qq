# 0.29.1 · 补齐 JNI 能力文档与事件投递顺序

- 修复恢复会话时待审批申请与广播事件的序列号分配竞争：连接本地申请不进历史缓冲，但与广播共用投递锁和序列时钟，避免同一连接收到较小序列号的事件在较大序列号之后。
- 文档明确 `typing`、`mark_read` 是 ambient 实际可用的 JNI 扩展；输入状态仍默认关闭并按 best-effort 使用。`mark_read_seq` / `mark_all_read` 不自动触发。
- 更新 JNI 能力盘点：ambient 不需要接入批量查询、搜索、OCR、收藏表情库或自动在线状态修改等接口；现有输入状态、显式已读、消息元素与素材发送已覆盖其需求。

`./test.sh` 通过。`typing` 的 QQ 客户端显示效果及内核回调依赖当前设备和 QQ 版本，需在目标版本真机验证；本次未将静态接口存在等同于现场验证。
