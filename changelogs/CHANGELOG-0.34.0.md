## 0.34.0

知弦会自己检查更新了，应用和模块都能在首页一键更新。

### 新增

- 首页顶部出现「更新」卡：发现新版本时写明版本变化，点「更新」就下载、校验、安装；点「更新内容」先看这版改了什么。
- 模块装好后出现「重启手机后生效」卡，带「立即重启」按钮。Zygisk 模块要重启才合并，这一步不再靠自己记。
- 还没装模块时，卡片直接给「安装模块」。
- 自动检查：打开知弦时检查（6 小时内不重复），每天在后台再检查一次，有新版本时发通知（Android 13 起需要允许通知）。「更新」区块里可以关掉，也可以随时手动「检查更新」。
- 模块的 `module.prop` 带上了 `updateJson`：在 Magisk / KernelSU / APatch 的模块页里，知弦也会显示「有更新」，可以直接在那里更新。
- 没有 root 授权、找不到模块安装命令、或安装器报错时，更新包会放进「下载」文件夹，卡片给出「用管理器安装模块」「安装应用」按钮，装完同样提示重启。

### 做法

- 每次发布附带 `update.json`（同时给知弦与模块页读）和 `CHANGELOG.md`；检查走 `releases/latest/download/update.json`，不占 GitHub API 的访问配额。
- 下载后核对 SHA-256；APK 还要核对包名、版本号和签名与当前应用一致，签名不同就不装。
- 先装模块、后装应用（应用更新会替换自己）；应用装好后由新版本的进程重新打开界面。
- root 被拒绝后，自动检查不再反复去敲门（避免 Magisk 每次弹授权框）；你主动点「更新」不受限。

### 升级到这一版

之前的版本没有更新功能，需要手动装一次 `SatoriQQ.apk` 与 `SatoriQQ-module.zip`；之后就可以在应用里更新。
