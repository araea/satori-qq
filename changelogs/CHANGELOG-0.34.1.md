# 0.34.1 — 适配 QQ 9.3.75

QQ 升到 9.3.75（versionCode 16580）后核对了一遍，模块照常工作，这一版不改行为，只收紧升级时的自检。

### 核对结果

- 新旧安装包签名对比：模块用到的内核服务（消息、群、富媒体、会话）只新增方法，没有删改；
  写入的 27 个结构体、全部字段都还在；源码点名的类一个没少。
- 真机：`internal/compat` 全部通过；acumen 冒烟 24/24；全量功能巡检 58 项里 57 项通过。
  没过的是戳一戳：被戳的那几个测试群成员，服务端回 `Process_Nudge failed`（9.3.65 时期也出现过）；
  对别的成员照常能戳，所以不是协议问题。

### 改动

- **`internal/compat` 的表与源码重新对齐**：原表里 44 个类型、整张结构体字段表都是早已不用的接口，
  在用的 16 个回调反而没列进去——自检通过并不代表在用的接口没变。现在核对 83 个类型、36 个回调、
  27 个结构体（取自源码里真正会写入的字段）。
- `test.sh` 新增一步 `scripts/compat-table.py --check`：表与源码对不上就失败，以后不会再悄悄漂移。
- 新增 `scripts/dex-diff.py <旧 apk> <新 apk>`：升级 QQ 之前就能比出模块用得到的接口变了什么，不用 jadx。
- 删掉 `ExtraSvc` 里 56 个没人用的类名常量；设精华、设头衔、等级头衔三处不再按版本猜类名与字段，
  直接用 9.3.75 的确切名字。

改动在 Java 层，代码内嵌在 Zygisk 的 `.so` 里：装机后**重启手机**才生效。
