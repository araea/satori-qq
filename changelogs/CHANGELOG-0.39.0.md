# 0.39.0 — 成员资料带上最后发言时间

`guild.member.get` / `guild.member.list` 的每个成员多两个扩展字段：

- `last_sent_at`：QQ 服务器记的这个人最后一次在群里说话的时刻（毫秒；0 = 进群以来没说过话）。机器人离线那几天的发言它也记着——知微的「潜水清理」靠它判断谁多久没说话，不会因为自己没收到消息就把人当成潜水；
- `level`：群等级（QQ 群里的 LV 数字）。

`guild.member.list` 新增 `refresh: true`：先向服务器重新拉一遍名单再返回（只在第一页生效，翻页沿用同一份）。不带时仍读 QQ 本地缓存，缓存里的最后发言可能停在上次有人打开成员列表的时候。
