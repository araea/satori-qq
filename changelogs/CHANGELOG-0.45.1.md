# 知弦 0.45.1：摘头衔的回读修正

0.45.0 的 `role=off` 已经真的清掉专属头衔并换回群主身份头衔，但回读校验拿
`-2`（“摘”的哨兵值）去比实际戴上的 `300`，于是回包写 `worn:false`、
`reason:not_reflected`。acumen 会把它说成“已上报但还没看到”，和实际状态相反。

## 修复

- `role=off` 戴回默认头衔后，把用于回读比较的 `title_id` 改成实际戴上的那一枚。
- 没有目标头衔时 `worn_title_id` 回 `0`，不再出现 `-1`。

行为与 0.45.0 相同，只是回包不再自相矛盾。升级后仍需重启手机让 Zygisk 换上新模块。
