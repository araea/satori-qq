# 知弦 0.48.1：防撤回图片双通道预取

## 修复图片经常取不到

收到图片但本地还没有文件时，资源回读现在同时尝试 QQ 图床直链与内核 `downloadRichMedia`，哪一路先拿到完整图片就返回哪一路：

- 不再先串行等待内核 30 秒，导致客户端已经超时，图床后备还没开始。
- 两路共享 25 秒上限，给客户端的 30 秒预取超时留出 HTTP 回包时间。
- 一路失败不会拖住另一路；成功的直连图片也登记为本地资源，后续读取不再重复下载。
- 只调整图片资源解析，语音、视频、文件的下载策略不变，`internal:` 资源链接与 Satori 协议形状保持原样。

这主要改善防撤回、取图、转发等「收到后马上预取」的场景；原消息撤回后仍可从已落盘的本地文件回读。
