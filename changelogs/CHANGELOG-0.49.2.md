# 知弦 0.49.2：新人进群就欢迎，不再等慢回调

## 新版 JSON 入群灰条被丢掉了

QQ 9.3.80 会用 `subElementType=17 / busiId=1022`（`RELATION_GROUP_MEMBER_ADD`）通知成员入群。实现端原来只从 JSON 灰条里识别戳一戳，入群则依赖 XML、`groupElement` 或 `onMemberListChange`：

- 即时到达的 JSON 入群通知被记为 `unparsed grayTip` 后丢弃
- 只能等较慢的成员列表变化回调补发 `guild-member-added`
- 下游欢迎逻辑本身没有合并等待，因此看到的就是「QQ 已显示新人进群，欢迎却很久才到」

## 改法

- 识别 `1022`，同时覆盖同语义的 `1015 / 1016` 入群变体，从 `items[]` 的 `uid`（必要时从 `uin` 或名片链接）定位新成员
- 灰条里的显示昵称直接放进 `member_name`，不必为了欢迎再补一次资料查询；uid → QQ 号暂时解析失败时不制造 `user_id=0` 的假事件，仍由成员列表回调兜底
- 成员事件去重移到统一事件出口：即时灰条与慢成员列表回调无论谁先到，同一次入群只投递一次；相反方向会解除旧状态，退群后重新入群不会被吞
- 不增加轮询，也不在欢迎链路新增等待或网络 API 调用
