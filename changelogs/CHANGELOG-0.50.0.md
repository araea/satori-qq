# 知弦 0.50.0：身份查询不再报旧的、不再冒充「普通成员」

## 现象

账号已经是群管理员，acumen 的入群验证却判定「不是管理员」、整个跳过。

## 原因

- 成员表拉下来之后就不再刷新：账号后来被设成管理员，`guild.member.get` 问自己，答的仍是几小时前那一行里的「普通成员」
- 成员表一时拉不下来（内核 4 秒没回调）时直接报错，调用方只能当自己不是管理员
- 消息事件里，发言者的身份说不准时（成员表还没拉）写成 `member`，接收方以为是查过的结果
- 内核推来的成员资料变更（`onMemberInfoChange`）没有接，身份变了没人知道

## 改法

- 账号本人的身份改读群资料里的 `memberRole`：群资料由内核推送维护，被设成管理员时立刻跟着变；`guild.member.get` 问自己、消息事件里自己的发言都以它为准
- 成员表一时拉不下来、问的又是账号自己时，先答身份（名字留空），不再报错
- 成员表拉了超过 10 分钟，`guild.member.get` 照常用缓存回答，同时后台向服务器要一份新的
- 接上 `onMemberInfoChange`：变更并进成员表；任何人身份变了（含账号自己），推 `guild-member-updated`，带 `_type=satori-qq/role`、`_data.role` 与 `member.roles`
- 发言者身份说不准时消息事件不带 `member.roles`，不再写成 `member`
