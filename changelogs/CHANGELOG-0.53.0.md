# 知弦 0.53.0：群管理补齐，资料卡点赞回来了

## 群管理

- **群详情** `group_detail`：群主、建群时间、人数与上限、群介绍、全员禁言到几时，以及本号在群里的身份、入群时间、接收方式、是否置顶，整理成固定字段
- **群设置** `group_settings`（群主或管理员）：加群方式、入群问题与答案、成员能否邀请、能否被搜到、发言频率、群介绍。只改带了的那几项，其余不动；什么都不带就读当前设置
- **批量踢人 / 批量禁言** `group_kick` / `group_mute`：一次处理多人，踢人可带理由、可拒绝再次申请
- **转让群** `group_transfer`、**解散群** `group_destroy`（要再写一遍群号确认）
- **群消息接收方式** `group_msg_mask`：接收并提醒、接收不提醒、收进群助手、屏蔽
- **会话置顶** `session_top`、**拉黑** `friend_block`
- **一次改本号在多个群的群名片**：`card` 带 `guild_ids[]` 或 `all: true`，每个群单独限频，回执逐群列出

## 账号资料

- **一次改几项资料** `profile_set`：昵称、签名、性别、生日
- **在线状态** `online_status`：在线、离开、隐身、忙碌、Q我吧、请勿打扰
- **资料详情** `user_info`：昵称、备注、签名、性别、年龄、生日、地区、学校、注册时间、会员与等级，整理成固定字段
- **资料卡点赞** `like`：0.23 去掉钩子时一起下线的点赞回来了。改由本端编码手机 QQ 的 `VisitorSvc.ReqFavorite`（JCE），经已有的裸 SSO 通道收发，不再需要钩子；失败时带服务端原文（比如对方设置了不许赞）

以上都在 `internal/capabilities` 的目录里，踢、禁言、转让、解散、群设置归为 `manage`。

## 验证

JVM 单元测试 37 项通过（新增 JCE 编解码与能力目录的用例）。新动作的内核调用签名按 QQ 9.3.80 安装包核对，群设置的写法照 QQ 自己的 `TroopOperationRepo`；要重启手机让新 .so 生效后才能在真机上跑。加群方式的名字与数字的对应、点赞的 WUP 包在真机上还没跑过。
