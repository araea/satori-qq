# 知弦设计规范 · 0.26

知弦是 Android 原生 Satori 管理应用。用户首先需要知道连接是否就绪、断在哪里、下一步做什么，再进入设置或诊断。视觉采用统一的紫色品牌、语义状态色、富有表现力的标题和圆角容器；不混用其他体系的组件皮肤。

## 冲突裁决

**平台原生规范 > 可用性与无障碍 > 产品一致性 > M3E > Carbon > Miuix**。

| 来源 | 在知弦中的职责 | 边界 |
| --- | --- | --- |
| Android 原生 | 返回、键盘、密码输入、系统文件选择器、安全区、窗口尺寸与开关语义 | 不仿制 iOS 导航或手势 |
| Apple HIG | 清晰的操作层级、及时反馈、保留草稿、确认破坏性动作 | 作为交互原则，冲突时服从 Android |
| Material 3 Expressive | 语义颜色、文字层级、色调容器、胶囊选中态、按钮形状动效 | 不牺牲文字可读性和操作目标 |
| Carbon | 表单分组、定义列表、复杂信息的渐进呈现与响应式组织 | 不引入 Web 组件；600/840dp 断点采用 Android 窗口规范 |
| Miuix | 圆角衔接、留白和表面层次精修 | 不增加另一套颜色、字级或交互规则 |

具体裁决：中文取消拉丁文的额外字距；字号达到 150% 时取消双列与侧边导航，保存区进入滚动内容；破坏性操作保留独立的文字与错误色边界；关闭系统动画时不做形状动效。固定品牌色便于持续验证并与图标保持一致，不意味着动态色无法满足对比度。

## Design Tokens

依赖方向固定为资源令牌 → `Tokens` → `Widgets` / `Responsive` → 页面。新增组件先复用语义角色，禁止在页面引入十六进制颜色。

| 类别 | 唯一来源 | 使用规范 |
| --- | --- | --- |
| 颜色 | `res/values/tokens.xml`、`res/values-night/tokens.xml` | 同名角色成对；surface 表面、on_* 文字、primary 主操作、success/warning/error 状态 |
| 文字 | `res/values/dimens.xml` 的 `md_type_*` | 36sp 状态标题、28sp 页标题、22sp 区块标题、16/14sp 正文；跟随系统字号 |
| 间距 / 形状 | `md_space_*`、`md_shape_*` | 基本间距 4/8/12/16/24/32/48dp；主卡片 28dp、次级卡片 20dp、输入框 12dp |
| 触控 / 结构 | `md_size_*` | 操作目标至少 48dp，按钮至少 52dp，输入框至少 56dp；96dp 侧边导航；弹窗最大 560dp |
| 动效 / 状态 | `md_motion_*`、`md_easing_*`、`md_state_*` | 短按形状变化、切页淡入；尊重系统动画开关；不靠动效承载唯一信息 |
| 响应式 | `md_bp_medium`、`md_bp_expanded` | 600dp 开始侧边导航，840dp 开始可用双列偏好；均受字号与实际可用宽度约束 |

浅色与深色的正文色对至少 4.5:1，必要控件边界及焦点至少 3:1。`DesignTokenTest` 覆盖两套色板的色对、角色集合、尺寸与资源引用。透明 ripple 和禁用态不用于承载独立状态信息。

## 组件契约

| 组件 | 规范 | 状态与无障碍 |
| --- | --- | --- |
| 导航栏 / 侧边导航 | 同一组状态、设置、诊断入口；选中胶囊 | 名称、按钮角色、selected 状态、波纹与独立焦点环；文字不省略 |
| 服务主卡片 | 结论 → 原因 → 下一步；主要操作放在卡片内 | 检查中、尚未连接、服务待恢复、等待登录、连接就绪；颜色同时配文字 |
| 连接链路 | QQ 账号 → 本机服务 → Satori 客户端 | 未取得数据时显示未知或待连接，绝不将其显示为已就绪 |
| 按钮 | 主操作填充、次操作色调、辅助文字、危险描边 | 文字随字号换行；禁用态不能点击；键盘焦点可见 |
| 开关 | 整行可点，系统 Switch 保留语义 | 名称、checked 状态、焦点环；说明文字独立换行 |
| 输入框 | 常驻标签、辅助说明、就地错误 | `labelFor`、密码输入语义、错误时聚焦并滚入可见区域；允许粘贴令牌 |
| 保存区 | 普通字号固定在内容下方；大字号随页面滚动 | 位于布局流中，避免覆盖输入焦点；修改提示为 polite 状态消息；保存与生效分别反馈 |
| 确认弹窗 | 同一色板与按钮体系；窄屏或大字号竖排操作 | 可滚动内容、最大宽度、默认焦点取消；系统返回可关闭 |
| 诊断列表 | 标签和值一一对应，窄屏上下排列 | 内容完整换行；复制 / 系统导出；报告不包含令牌或消息 |

令牌默认隐藏，显示期间使用 FLAG_SECURE，离页或进入后台重新隐藏。撤销草稿须确认；切换页面不清空草稿。自动刷新可以暂停，暂停后仍可手动刷新。页面退出不会停止 QQ 服务。

## 验证与范围

目标是按照 WCAG 2.2 AA 的适用要求实现 Android 原生界面，不将自动测试等同于完整合规认证。

- `bash test.sh`：颜色对比度、资源、实例状态契约及业务回归。
- `bash tests/ui/run.sh`：真实 Android 视图中的输入校验、保存、令牌隐私、状态语义、48dp 目标、焦点环像素检查、320dp / 200% 字号、900dp 侧边导航与保存区。
- 生成浅色、深色、大字号、宽屏的 12 张长页排版截图；数据使用明确的测试样本，不能作为真实在线凭证。
- 发布前人工复核截图。TalkBack 连续操作、外接键盘遍历、不同 OEM 键盘与旋转/分屏仍需要设备矩阵验收，测试报告应如实记录范围。

WCAG 对照：1.3.1 标签与结构；1.4.1 非颜色唯一表达；1.4.3 / 1.4.11 对比度；1.4.4 / 1.4.10 字号与重排；2.1.1 键盘；2.2.2 可暂停自动更新；2.4.7 / 2.4.11 焦点可见且不被固定区覆盖；2.5.8 目标大小；3.3.1 / 3.3.2 错误与说明；4.1.2 / 4.1.3 名称、角色、状态消息。
