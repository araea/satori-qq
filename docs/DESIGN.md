# 知弦设计规范 · 0.27

知弦是 Android 原生的 Satori 管理应用。打开它的人只想知道三件事：**服务通了没有、断在哪一环、下一步做什么**。
其次才是改端口与令牌、控制常驻守护、导出诊断。整个界面围绕这个顺序组织，其余一概不做。

0.27 从零重写：旧的三页底部导航、自动刷新开关、文件导出、每 5 秒走动的时钟都已删除。

## 体系分工与裁决

冲突时按 **平台原生 > 可用性与无障碍 > 产品一致性 > M3E > Carbon > Miuix** 裁决。每个体系只在自己的职责里出现，
不拼贴另一套组件的外观。

| 来源 | 在知弦中负责 | 不负责 |
| --- | --- | --- |
| Android 平台 | 全屏绘制与安全区、系统返回与预测性返回、对话框按钮顺序、剪贴板确认、系统分享、`FLAG_SECURE`、快捷设置磁贴 | — |
| Material 3 Expressive | **核心视觉语言**：颜色角色、字级与强调字级、形状刻度、弹簧动效、按压形状形变、分段列表、连接按钮组、加载指示器、信息条、开关 | 不牺牲对比度、目标尺寸与重排 |
| Apple HIG | **交互原则**：大标题随滚动收进顶栏、每屏一个主操作、层级导航、破坏性操作先确认且默认焦点在取消、保留草稿、离开前问保存 | 不仿 iOS 控件外观，不改 Android 的按钮顺序与返回语义 |
| Carbon | **复杂信息与响应式模式**：行内通知（结论 + 说明 + 动作）、表单（常驻标签、辅助文字、就地错误、提交时校验）、定义列表、列表-详情双栏 | 不引入 Web 组件；断点服从 Android 窗口尺寸类别 |
| Miuix | **视觉精修**：大容器的连续曲率圆角、分组标题的留白节奏 | 不改圆角数值、颜色、字级与交互 |

具体裁决记录：

- **固定品牌色，不跟随壁纸取色。** 动态色无法为任意壁纸保证 success / warning 两个自定义角色的对比度，也会与
  `#6750A4` 的应用图标分叉；可用性与产品一致性排在 M3E 之前。
- **中文取消字距。** M3 的拉丁文正字距会把汉字拆散；可用性优先。
- **对话框按钮顺序用 Android 的**（肯定操作在最右），而不是 HIG 的；采纳 HIG 的只有错误色与默认焦点。
- **圆角数值服从 M3E**（输入框 4dp、信息条 4dp、卡片 28/32dp），Miuix 只把大容器的角改成连续曲率——两者不冲突。
- **没有"暂停自动刷新"按钮。** 页面只在前台轮询，内容没有变化就不重绘也不朗读，不再有每 5 秒跳动的时钟；
  没有持续运动或自动变化的内容，WCAG 2.2.2 所针对的干扰不存在。手动刷新始终可用。
- **关闭系统动画时一切动效直接跳到终态**，动效从不承载唯一信息。

## 信息架构

```text
首页（状态）                         连接设置
├─ 大标题 知弦                       ├─ 大标题 连接设置
├─ 状态卡片：结论 → 说明 → 下一步     ├─ 行内通知：设置是否已生效（可一键重启 QQ）
├─ 指标：客户端数 · 连续在线          ├─ 连接：端口、令牌（显示/生成/复制）
├─ 连接链路：QQ 账号 → 本机服务 → 客户端 ├─ 运行偏好：4 个开关
├─ 连接：地址（复制）· 令牌（进入设置）  ├─ 配置来源：改用文件配置
├─ 常驻守护：开关 · 重启 QQ · 停止并关闭 └─ 保存栏（有改动时出现）
└─ 诊断：定义列表 · 复制 / 分享报告
```

- 窄屏：首页 → 设置是层级导航（顶栏右侧齿轮进入，左上返回），切换用 M3 共享轴 X 动效；Android 14+ 支持预测性返回。
- 宽屏（≥ 840dp 且每栏折算后 ≥ 360dp）：两页并列为列表-详情双栏，右栏降一级表面色，齿轮入口消失。
- 未连接时状态卡片内展开三步排查；就绪时卡片里没有按钮。

## Design Tokens

依赖方向固定：**资源令牌 → `Tokens` → 组件 → 页面**。令牌经 aapt 生成的 `R` 类引用，名字拼错编译失败；
界面代码里不许出现字面色值或按名字查资源（`tests/DesignTokenTest` 拦截）。

| 类别 | 唯一来源 | 取值 |
| --- | --- | --- |
| 颜色 | `res/values/tokens.xml`、`res/values-night/tokens.xml` | M3 基线色板（源色 `#6750A4`）+ success / warning 两个补充角色；深浅两套角色集合完全一致 |
| 字级 | `dimens.xml` 的 `md_type_*` | 11 档，sp；字重 400 / 500 / 强调 600（状态标题、页面大标题） |
| 间距 | `md_space_*` | 2 / 4 / 8 / 12 / 16 / 24 / 32 / 48dp；2dp 只用于分段缝隙 |
| 形状 | `md_shape_*` | 4 / 8 / 12 / 16 / 20 / 28 / 32dp，外加胶囊（按高度取半） |
| 尺寸 | `md_size_*` | 触达 48dp；按钮 48 / 突出 56；输入框 56；列表单行 56、双行 72；顶栏 64；开关 52×32，把手 16 / 24 / 按下 28 |
| 动效 | `md_spring_*` | 空间弹簧（标准 ζ0.9：快 1400、默认 700；表现力 ζ0.6：快 800）、效果弹簧（ζ1.0：3800 / 1600） |
| 状态层 | `md_state_*` | 悬停 8%、按压 10%、禁用容器 12%、禁用内容 38%；遮罩 32% |
| 响应式 | `md_bp_*`、`md_reflow_*` | 600 / 840dp；双栏每栏 ≥ 360dp、并排每行 ≥ 280dp，均按 **宽度 ÷ 字号倍率** 判断 |

弹簧折算成框架动画的时长与插值器（`ui/Spring`），不依赖 androidx。

## 组件契约

| 组件 | 外观（M3E） | 交互与无障碍 |
| --- | --- | --- |
| 顶栏 `TopBar` | 64dp + 状态栏；滚过大标题后小标题淡入、底色升一级 | 小标题不进读屏树，页面大标题才是 heading |
| 按钮 `Btn` | 胶囊；填充 / 色调 / 描边 / 文字 / 危险；按下形变到 12dp 圆角并回弹 | ≥ 48dp；标签可换行；内侧焦点环；禁用不可点 |
| 图标按钮 | 40dp 圆、48dp 点击区 | contentDescription + tooltip |
| 连接按钮组 | 并排、2dp 缝隙、内侧 8dp 角 | 大字号或窄屏竖排 |
| 分段列表 `Ui.Group` + `Item` | 2dp 缝隙，首尾 28dp、中间 4dp 连续曲率角 | 静态 / 按钮 / 开关三种角色；整行可点 |
| 开关行 | 轨道 52×32；关：描边 + 16dp 灰把手；开：主色 + 24dp 把手带对勾；按下 28dp | 整行读作「开关，已开启/已关闭」；开关图形不进读屏树 |
| 输入框 `Field` | 4dp 描边框；聚焦 2dp 主色；错误 2dp 错误色 | 常驻标签 `labelFor`；辅助文字；错误时图标 + 文字 + `setError`，聚焦并滚入视野；令牌禁止个性化学习 |
| 行内通知 `Notice` | 16dp 色调容器 + 状态图标 | 整块 polite live region；可带一个动作 |
| 状态卡片 | 32dp 连续曲率角，按状态换容器色 | 标题与说明是 live region；颜色之外还有图标与文字 |
| 定义列表 | 标签定宽 120dp 与值同行；窄屏上下排 | 每行读屏整体朗读，不占键盘焦点 |
| 对话框 `Dialogs` | 28dp 连续曲率角、文字按钮、宽 280–560dp | 默认焦点在取消；返回与点遮罩 = 取消；内容可滚动；大字号竖排 |
| 信息条 `Snackbar` | 反色表面、4dp 角、至多一个动作 | 停留时间取系统「操作时限」；TalkBack 开启且带动作时不自动消失 |
| 加载指示器 | 瓣数连续形变并旋转的实心图形 | 装饰性；只在首次检查时出现 |

## 交互约定

- **设置**：有改动才出现保存栏（大字号时进入滚动内容，不常驻底部）；保存时校验，出错字段就地提示并获得焦点；
  放弃修改、离开未保存的页面都先确认（取消 / 放弃 / 保存）；草稿跨实例重建保留。
- **令牌**：默认隐藏；显示期间窗口 `FLAG_SECURE`，离开设置页或应用进入后台立即重新隐藏；复制时标记为敏感内容。
- **生效**：保存只写本机，QQ 下次启动时读取。页面比对 QQ 回报的修订号，说清"已生效 / 等待重启 / 被系统拦截"，
  并提供「重新启动 QQ」——它先暂停守护、关 QQ、重新打开，再恢复守护，不会因为强行停止而把保活悄悄关掉。
- **危险操作**：「停止保活并关闭 QQ」「重新启动 QQ」都需要确认。
- **复制**：Android 13 起系统自己提示复制结果，应用不再重复提示。

## 性能

- 不解析 XML 布局，视图直接构造；设置页在首次进入时才建。图标路径在类加载时建一次、全局共享。
- 主线程零 I/O：设置文件与回环探测在一条工作线程，root 调用在另一条（`su` 最长 20 秒，不能堵住保存与刷新）。
- 只在前台轮询（在线 5 秒、离线 10 秒）；文本只在变化时写入，轮询不引起重排，也不重复触发读屏播报。
- root 状态只在回到前台（超过 15 秒未读）与操作之后读取，不随轮询调用 `su`。
- 注入 QQ 的 dex 不含 `ui/`、`guard/` 与 `R`：QQ 进程从不加载它们。

## 验证与范围

目标是按 WCAG 2.2 AA 的适用要求实现原生界面，不把自动测试等同于合规认证。

- `./test.sh`：色对比度（深浅两套、文字 27 对 ≥ 4.5、非文字 12 对 ≥ 3）、刻度与弹簧参数、`R` 引用、状态推导（`StatusTest`）、
  实例状态与稳定 id 契约（`UiContractTest`）及其余业务回归。
- `bash tests/ui/run.sh`（真机）：状态卡片三种状态、读屏角色与状态、live region、两页所有可操作控件 ≥ 48dp、
  键盘焦点环像素变化、危险操作确认与默认焦点、表单校验与保存、草稿进入实例状态、离开前确认、令牌隐私与 `FLAG_SECURE`、
  200% 字号 + 320dp 两页文字无截断且控件不缩、大字号对话框、900dp 双栏；并输出 8 张长页截图供人工复核。
- 尚需人工或设备矩阵验收：TalkBack 连续操作、外接键盘遍历、不同厂商输入法、旋转与分屏、预测性返回手势。

WCAG 对照：1.3.1 结构与标签；1.4.1 不只靠颜色；1.4.3 / 1.4.11 对比度；1.4.4 / 1.4.10 / 1.4.12 缩放、重排与文字间距；
2.1.1 键盘；2.2.1 时限可调；2.4.6 标题与标签；2.4.7 / 2.4.11 焦点可见且不被遮挡；2.5.8 目标尺寸；
3.3.1 / 3.3.2 错误识别与说明；3.3.4 防误操作；4.1.2 名称、角色、状态；4.1.3 状态消息。
