# 知弦设计规范

知弦是 Android 原生 Satori 管理应用，界面围绕状态、连接设置、常驻守护与诊断组织。

## 体系裁决

冲突时按 **平台原生 > 可用性与无障碍 > 产品一致性 > M3E > Carbon > Miuix** 裁决。各体系只在自己职责内出现，不拼贴另一套组件外观。

| 来源 | 负责 | 不负责 |
| --- | --- | --- |
| Android 平台 | 全屏绘制与安全区、系统返回与预测性返回、对话框按钮顺序、剪贴板确认、系统分享、`FLAG_SECURE`、快捷设置磁贴 | — |
| Material 3 Expressive | 核心视觉语言：颜色角色、字级与强调字级、形状刻度、弹簧动效、按压形变、分段列表、连接按钮组、加载指示器、信息条、开关 | 不牺牲对比度、目标尺寸与重排 |
| Apple HIG | 交互原则：大标题随滚动收进顶栏、每屏一个主操作、层级导航、破坏性操作先确认且默认焦点在取消、保留草稿、离开前问保存 | 不仿 iOS 控件外观，不改 Android 按钮顺序与返回语义 |
| Carbon | 复杂信息与响应式模式：行内通知、表单、定义列表、列表-详情双栏 | 不引入 Web 组件；断点服从 Android 窗口尺寸类别 |
| Miuix | 视觉精修：大容器连续曲率圆角、分组标题留白节奏 | 不改圆角数值、颜色、字级与交互 |

关键裁定：固定品牌色不跟随壁纸取色，保证 success / warning 对比度并避免与 `#6750A4` 应用图标分叉；中文取消字距；对话框按钮顺序用 Android 的（肯定操作在最右）；圆角数值服从 M3E（输入框与信息条 4dp、卡片 28/32dp）；无「暂停自动刷新」按钮，页面仅前台轮询；关闭系统动画时动效直接跳终态。

## 设计令牌

依赖方向固定：资源令牌 → `Tokens` → 组件 → 页面。令牌经 aapt 生成的 `R` 类引用，名字拼错编译失败；界面代码不得出现字面色值或按名查资源（`tests/DesignTokenTest` 拦截）。

| 类别 | 来源 | 取值 |
| --- | --- | --- |
| 颜色 | `res/values/tokens.xml`、`res/values-night/tokens.xml` | M3 基线色板（源色 `#6750A4`）+ success / warning 两补充角色；深浅两套角色一致 |
| 字级 | `dimens.xml` 的 `md_type_*` | 11 档，sp；字重 400 / 500 / 强调 600 |
| 间距 | `md_space_*` | 2 / 4 / 8 / 12 / 16 / 24 / 32 / 48dp；2dp 仅用于分段缝隙 |
| 形状 | `md_shape_*` | 4 / 8 / 12 / 16 / 20 / 28 / 32dp，外加胶囊（按高度取半） |
| 尺寸 | `md_size_*` | 触达 48dp；按钮 48 / 突出 56；输入框 56；列表单行 56、双行 72；顶栏 64；开关 52×32，把手 16 / 24 / 按下 28 |
| 动效 | `md_spring_*` | 空间弹簧（标准 ζ0.9：快 1400、默认 700；表现力 ζ0.6：快 800）、效果弹簧（ζ1.0：3800 / 1600） |
| 状态层 | `md_state_*` | 悬停 8%、按压 10%、禁用容器 12%、禁用内容 38%；遮罩 32% |
| 响应式 | `md_bp_*`、`md_reflow_*` | 600 / 840dp；双栏每栏 ≥ 360dp、并排每行 ≥ 280dp，均按 宽度 ÷ 字号倍率 判断 |

弹簧折算成框架动画的时长与插值器（`ui/Spring`），不依赖 androidx。

## 组件契约

| 组件 | 外观（M3E） | 交互与无障碍 |
| --- | --- | --- |
| 顶栏 `TopBar` | 64dp + 状态栏；滚过大标题后小标题淡入、底色升一级 | 小标题不进读屏树，页面大标题才是 heading |
| 按钮 `Btn` | 胶囊；填充 / 色调 / 描边 / 文字 / 危险；按下形变到 12dp 圆角并回弹 | ≥ 48dp；标签可换行；内侧焦点环；禁用不可点 |
| 图标按钮 | 24dp 图标、40dp 圆、48dp 点击区；刷新用 Material Icons Round 官方矢量路径（Apache-2.0），颜色取令牌 | contentDescription + tooltip |
| 连接按钮组 | 并排、2dp 缝隙、内侧 8dp 角 | 大字号或窄屏竖排 |
| 分段列表 `Ui.Group` + `Item` | 2dp 缝隙，首尾 28dp、中间 4dp 连续曲率角 | 静态 / 按钮 / 开关三种角色；整行可点 |
| 开关行 | 轨道 52×32；关：描边 + 16dp 灰把手；开：主色 + 24dp 把手带对勾；按下 28dp | 整行读作「开关，已开启/已关闭」；开关图形不进读屏树 |
| 输入框 `Field` | 4dp 描边框；聚焦 2dp 主色；错误 2dp 错误色 | 常驻标签 `labelFor`；辅助文字；错误时图标 + 文字 + `setError`；令牌禁止个性化学习 |
| 行内通知 `Notice` | 16dp 色调容器 + 状态图标 | 整块 polite live region；可带一个动作 |
| 状态卡片 | 32dp 连续曲率角，按状态换容器色 | 标题与说明是 live region；颜色之外还有图标与文字 |
| 定义列表 | 标签定宽 120dp 与值同行；窄屏上下排 | 每行读屏整体朗读，不占键盘焦点 |
| 对话框 `Dialogs` | 28dp 连续曲率角、文字按钮、宽 280–560dp | 默认焦点在取消；返回与点遮罩 = 取消；内容可滚动 |
| 信息条 `Snackbar` | 反色表面、4dp 角、至多一个动作 | 停留取系统「操作时限」；TalkBack 开启且带动作时不自动消失 |
| 加载指示器 | 瓣数连续形变并旋转的实心图形 | 装饰性；仅首次检查时出现 |

## 交互约定

- 设置：有改动才出现保存栏；保存时校验，出错字段就地提示并获得焦点；放弃或离开未保存页面先确认；草稿跨实例重建保留。
- 令牌：默认隐藏；显示期间窗口 `FLAG_SECURE`，离开或进后台立即重新隐藏；复制时标记为敏感内容。
- 生效：保存只写本机，QQ 下次启动读取。页面比对 QQ 回报的修订号，说明「已生效 / 等待重启 / 被系统拦截」，并提供「重新启动 QQ」：先暂停守护、关 QQ、重开，再恢复守护，不会因强行停止悄悄关掉保活。
- 危险操作：「停止保活并关闭 QQ」「重新启动 QQ」都需确认。
- 复制：Android 13 起系统自己提示复制结果，应用不再重复提示。

## 性能

- 不解析 XML 布局，视图直接构造；设置页首次进入才建。图标路径类加载时建一次、全局共享。
- 主线程零 I/O：设置文件与回环探测一条工作线程，root 调用另一条（`su` 最长 20 秒，不堵保存与刷新）。
- 只在前台轮询（在线 5 秒、离线 10 秒）；文本仅变化时写入，轮询不引起重排，也不重复触发读屏播报。
- root 状态只在回前台（超 15 秒未读）与操作后读取，不随轮询调用 `su`。
- 注入 QQ 的 dex 不含 `ui/`、`guard/` 与 `R`：QQ 进程从不加载它们。

## 验证

目标：按 WCAG 2.2 AA 适用要求实现原生界面，不把自动测试等同合规认证。

- `./test.sh`：色对比度（深浅两套、文字 27 对 ≥ 4.5、非文字 12 对 ≥ 3）、刻度与弹簧参数、`R` 引用、状态推导（`StatusTest`）、实例状态与稳定 id 契约（`UiContractTest`）及业务回归。
- `bash tests/ui/run.sh`（真机）：状态卡片三态、读屏角色与状态、live region、两页所有可操作控件 ≥ 48dp、键盘焦点环像素变化、危险操作确认与默认焦点、表单校验与保存、草稿进入实例状态、离开前确认、令牌隐私与 `FLAG_SECURE`、200% 字号 + 320dp 两页文字无截断且控件不缩、大字号对话框、900dp 双栏；输出 8 张长页截图供人工复核。
- 待人工或设备矩阵验收：TalkBack 连续操作、外接键盘遍历、不同厂商输入法、旋转与分屏、预测性返回手势。

WCAG 对照：1.3.1 结构与标签；1.4.1 不只靠颜色；1.4.3 / 1.4.11 对比度；1.4.4 / 1.4.10 / 1.4.12 缩放、重排与文字间距；2.1.1 键盘；2.2.1 时限可调；2.4.6 标题与标签；2.4.7 / 2.4.11 焦点可见且不被遮挡；2.5.8 目标尺寸；3.3.1 / 3.3.2 错误识别与说明；3.3.4 防误操作；4.1.2 名称、角色、状态；4.1.3 状态消息。
