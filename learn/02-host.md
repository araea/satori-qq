## 安卓进程

**为什么。** 模块不是一个独立 App 在旁边偷看 QQ。它被装进 QQ 的进程里，和 QQ 共用地址空间、ClassLoader、网络栈。QQ 死，它就死。

**怎么用到。** `Main` 里先比 `packageName`，再比 `processName`。只在主进程跑。`:MSF` 是 QQ 的另一间屋子，NT 会话不在那里，进去也钩不到要用的对象。

**去学。** 安卓「多进程」：同一个包名可以有多个进程。`Activity`、后台服务、`:xxx` 进程各是什么。不必会写界面。问自己：我的代码在哪一个 `pid` 里？

## QQNT

**为什么。** 现在的手机 QQ 不是旧协议那个壳。业务在 NT 内核：会话、消息服务、资料服务。外面包一层 Java JNI。认错年代，会去 hook 已经不存在的接口。

**怎么用到。** 抓住 `IQQNTWrapperSession$CppProxy` 的实例，再 `getMsgService()` 这类名字稳定的方法。群号和好友 uid 不是同一种东西；私聊必须 uid。

**去学。** 不必研究腾讯内部架构图。只要建立三个词：会话、服务、元素（一条消息里的一块）。然后打开 `docs/ARCHITECTURE.md` 的表，对着 jadx 看同一份名字。

## 在线与掉线

**为什么。** 端口开着不等于账号在。登录页、NT 会话没就绪、监听没挂上，都是「不在线」。机器人若把这些当成成功，会往黑洞里发消息。

**怎么用到。** `get_status` 看真实 online。离线动作快速失败 1500。进程被系统杀掉时，模块救不了自己，要靠进程外的 watchdog。

**去学。** 分清三件事：进程活着、端口在听、账号已登录。log 里再加第四件：被 OEM 冻住。`docs/STACK.md` 有一张「算不算踢号」的表，那是测验，不是阅读材料。
