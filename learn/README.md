learn
=====

这份目录不是教程，是地图。

仓库里的代码是战地笔记：它能跑，是因为作者在这台手机、这个 QQ 版本上把路走通了。后来者若只想「复现安装」，看仓库根目录的 README 和 `docs/`。若想明白**为什么必须是这些技术**、缺哪一块会整栋楼塌掉，从这里走。

每篇只回答三件事：为什么用、用在项目哪、还要去学什么。讲完就停。剩下的，打开对应源码自己看。

## 训练

没有一条课表能保证你写出这个仓库。下面是**能力闸门**：过不了，后面的篇对你只是字。

1. **当过用户。** 用过任意 OneBot 机器人（收发一条群消息）。不知道合同长什么样，不要谈实现端。
2. **能写 Java。** 类、接口、反射、线程、JSON。不必会安卓 UI。
3. **知道进程是什么。** 一个 App 可以有多个进程；代码进错进程等于没进。
4. **装过一个玩具 Xposed 模块。** hook 某个 App 的一个方法、改返回值、在 logcat 里看见自己。过不了这关，QQ 只是一个更大的玩具。
5. **用 jadx 打开过一个不是自己写的 APK。** 能从「我想发消息」找到一个类名和方法签名。不必会脱壳。
6. **手写或读懂过一段 WebSocket 或 HTTP。** 知道帧、握手、鉴权是三件不同的事。
7. **读过 ELF 或「动态链接」的入门。** 知道 GOT 不是魔法。C 不必精通，但要能读几十行系统调用。
8. **在真机上砸过一次。** 闪退、掉登录、端口在却不回包——三种失败要能分开。纸上的反检测没有用。

到第 4 关，你可以开始改这个仓库的 Java 表层。到第 7 关，你才有资格动 `native/`。到第 8 关，你才明白为什么文档反复写「能登录就不要卸 scope」。

训练时用小号、用测试群。主号是作者自己的选择，不是功课要求。
